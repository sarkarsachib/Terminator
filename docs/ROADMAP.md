# Roadmap

## Phase 1 (implemented)

- Core orchestrator runtime
- In-process message bus + bounded event log
- Component interfaces
- Output gating
- Protocol Buffer specification

## Phase 2 (next)

- gRPC bus adapter + service stubs
- Python learning services connected via RPC
- Durable persistence for event log and memory

## Phase 3+

- Multimodal input capture
- Knowledge graph + episodic/procedural memory
- Tool registry + 50+ tools
- Personality/autonomy policies
- Self-modification workflows (guardrails + review)
